# lpa-trabalho-b1# Simulador de Entregas - LPA B1

Projeto desenvolvido para a disciplina de Lógica de Programação e Algoritmos. O objetivo deste programa em C é simular o cálculo de tarifas de entrega com base na distância, peso, modalidade escolhida e custos adicionais.

## Estrutura do Projeto
- `src/main.c`: Ficheiro fonte principal contendo a lógica de cálculo, validações de entrada e o resumo final da sessão com contadores e acumuladores.
